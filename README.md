# DQWメモ — Phase 1

ゲーム画面の上に重ねて使う、フローティングメモアプリです。

## 起動

Windows のターミナルでこのフォルダーを開き、実行します。

```bash
python dqw_memo.py
```

## 使い方

1. **新規** でメモを作成します。
2. **タイトル** と **本文**（改行可）を入力し、**保存** します。
3. 左の **メモ一覧** から選択して呼び出します。
4. **更新して表示**（または `Ctrl + Enter`）でフローティングメモを開きます。
   表示内容は「タイトル + 空行 + 本文」です。
5. 表示中は編集内容がフローティングへ自動反映されます。
6. 「常に最前面」のチェックで、ゲーム画面より前に表示するかを切り替えられます。
7. フローティングウィンドウは標準タイトルバーまたはアプリ内見出しをドラッグして移動できます。ウィンドウ枠をドラッグすればリサイズできます。
8. フローティング側の × または **表示を閉じる** は、メイン画面を終了せずに表示だけを隠します。

## データ保存

- 保存先: `%LOCALAPPDATA%\DQW-Memo\memos.json`
  例: `C:\Users\<ユーザー>\AppData\Local\DQW-Memo\memos.json`
- 複数メモを JSON で永続化します（再起動後も残ります）。
- JSON 破損や権限エラー時はメッセージを表示し、アプリは終了しません。

## Phase 1 の対象外

DQW専用データ、PT構成、OCR、AI連携、ターン管理、クラウド同期、削除 UI、複雑な設定は含めません。

## テスト

