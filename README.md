# DQWメモ — Phase 1

ゲーム画面の上に重ねて使う、最小構成のフローティングメモアプリです。

## 起動

Windows のターミナルでこのフォルダーを開き、実行します。

```bash
python dqw_memo.py
```

## 使い方

1. メイン画面の「メモ本文」に任意の攻略メモを入力します。
2. **更新して表示**（または `Ctrl + Enter`）でフローティングメモを開きます。
3. 表示中は編集内容が自動反映されます。
4. 「常に最前面」のチェックで、ゲーム画面より前に表示するかを切り替えられます。
5. フローティングウィンドウは標準タイトルバーまたはアプリ内見出しをドラッグして移動できます。ウィンドウ枠をドラッグすればリサイズできます。
6. フローティング側の × または **表示を閉じる** は、メイン画面を終了せずに表示だけを隠します。

## Phase 1 の対象外

DQW専用データ、PT構成、OCR、AI連携、ターン管理、データベース、クラウド同期、複雑な設定は含めません。

## テスト

```bash
python -m unittest discover -s tests -v
```
